# InersiaLab Software Department — SEO Audit Engine (agy-seo)

An executive-grade technical, on-page, and Generative Engine Optimization (GEO) SEO audit toolkit.

## Features
- **Deep Multi-Page Crawling**: Traverses XML sitemaps and discovers internal links with native Arabic and Unicode URL support.
- **8 Comprehensive Analyzers**:
  1. Technical SEO & Security (Sitemap 404 penalties, HTTPS, security headers, canonicals)
  2. On-Page & Metadata (Titles, meta descriptions, semantic headings H1/H2/H3, OpenGraph)
  3. Content Quality & E-E-A-T (Word counts, reading ease, thin content detection)
  4. Schema & Structured Data (JSON-LD validation, Organization, MedicalBusiness, sameAs)
  5. Performance & Core Web Vitals (TTFB latency, render-blocking scripts, LCP, image CLS)
  6. Generative Engine Optimization (GEO / AI Search for SearchGPT, Perplexity, Claude, llms.txt)
  7. Images & Assets (Alt text, explicit dimensions, modern WebP/AVIF formats, lazy loading)
  8. Link Architecture (Broken links, anchor text signals, nofollow audit, orphan page detection)
- **Strict Executive Design**:
  - Exactly 3 colors: Black (#111827), Red (#b91c1c), Green (#15803d).
  - Pure white background (#ffffff), no colored background box fills, no box shadows, zero icons/emojis.
  - 50% / 50% balanced Problem & Solution tables with row-level page-break protection.
  - Large, bold problem tags ([CRITICAL DEFECT], [HIGH PRIORITY], [MEDIUM PRIORITY]).
  - Official attribution: 'Report generated by the Software Department of InersiaLab'.
  - All reports automatically saved directly to the user\'s Downloads folder.

## User Interfaces

- **Native Desktop GUI**: Run 
un_gui.bat (or python gui.py) for a clean, minimalist desktop application with real-time log stream and 1-click PDF viewer.
- **Web Browser UI**: Run 
un_web.bat (or python web_ui.py) to launch a local browser interface at http://127.0.0.1:8765.
- **Command Line**: Run 
un_audit.bat <URL> [MAX_PAGES] or python agy_seo.py audit <URL> --max-pages 10.

## Installation (For New Clones)

`ash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/seo-audit-engine.git
cd seo-audit-engine

# 2. Create and activate a virtual environment
python -m venv .venv
# On Windows:
.\.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Install Playwright browser
playwright install chromium
`
